# 正文写作

写前读当前规划、场景目标、近期正文和涉及的设定。以人物当下能感知的信息落笔；先让读者进入正在发生的事，不先替故事总结主题。

让情绪来自有后果的动作、选择和互动。细节服务于人物注意力：他为什么此时看到它、躲开它、误会它。不要给每段都安排比喻、金句或情绪解释。

对话包含意图与关系。人物可以答非所问、犹豫、隐瞒、转移话题；避免人人同样机智、完整解释背景。区分人物用词与反应，但不靠机械口头禅。

按动作、说话者、注意力或节奏自然分段。手机上避免整屏密集长段，也不要把每个短句都拆行；句式长短跟着场景变化，不用固定字数模板。

保留轻重缓急和必要留白。情绪回报要具体，章节结尾可留下行动、关系或信息上的牵引，不强制制造悬崖。

先完成能成立的场景，再自审明显问题。使用章节工具保存，修改时提交读取到的版本。正文以纯文本为基础，支持自然段；不要夹带 JSON、解释和检查清单。
