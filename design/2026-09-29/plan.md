# 催更姬视觉与交互方案：安静的写作工作台

状态：设计提案与可交互原型，尚未替换正式规划/资料界面。

当前原型的主导航名称为“正文 / 规划 / 设定”。下方早期记录中的“资料”均指现已改名的“设定”模块。

## 本轮已直接修复

- 自动排版不再显示成功或“无需调整”说明，撤销保留在工具栏。
- 移除 AI 参考按钮与抽屉；Agent 接手索引、工具和按需读取机制保留。
- 正文编辑器无边框、无悬停框、无整块焦点框，随全文高度增长。正文页面只有一个滚动区域。

## 方法与现状

本地未安装前端设计 Skill。本方案读取并采用 Anthropic 公开 frontend-design Skill 的指导：先定义视觉方向，以真实布局和交互原型落实，再检查渲染效果。本次仅使用其设计指导，未安装或更改全局 Skill。

来源：https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md（读取日期：2026-09-29）。

已核对当前规划首页、规划详情、资料列表、人物详情以及正文截图与组件源码。

核心问题不是缺少装饰，而是页面状态没有切开：打开详情后还显示首页的搜索、分组、筛选和新建工具；阅读页与编辑表单混合；元信息、正文与危险操作视觉权重接近；滚动区域嵌套；许多常驻说明只是解释按钮自身。

## 视觉方向

以书稿编辑桌为参考：暖灰背景、近白正文、墨色文字、克制的深绿强调色。留白用于区分阅读和操作，不用大空盒子撑版面。规划画布、正文和资料详情属于同一个产品。

- 强调色只用于当前导航、一个主要操作及选中对象，不在每个区域重复放彩色按钮。
- 工具文字使用系统中文无衬线；详情标题可用宋体风格；正文使用可读的 17–18px 字号、1.8–1.95 行高。
- 颜色映射到 DSH 主题变量；原型先验证亮色方向，正式接入必须补充深色模式验收，不能把纸白硬编码到宿主。
- 标题层级控制为作品、模块、内容标题三级；分组和状态使用小型辅助文字，不再反复加粗。
- 间距采用 4/8/12/16/24/32/48px；控件 36px，触摸设备至少 44px；圆角 6–10px，阴影仅用于浮层。

## 页面与操作预算

| 页面 | 常驻入口 | 进入菜单或按情境出现 | 移除/收起 |
| --- | --- | --- | --- |
| 规划首页 | 当前分组、搜索、新情节、更多 | 分组管理/筛选/历史/列表切换在更多；选节点后才出现续接/连接 | 常驻教学句、第二排分组管理、总是可见的连线删除提示 |
| 规划画布 | 内容节点；底部紧凑缩放工具 | 选中节点后显示操作；选中连线后显示删除 | 每张卡片都重复“有更新”“打开填写” |
| 资料首页 | 搜索、类型切换、分组、新建、更多 | 批量操作开启后才出现复选框；导入在更多 | 常驻复选框和空关系提示 |
| 所有详情页 | 返回、编辑、更多 | 关联对象和前后情节在正文之后；属性在折叠区 | 首页的整套工具；重复标题；无冲突时的读取/比较按钮 |
| 编辑详情 | 同位置标题、摘要和内容，保存/取消 | 当前任务相关属性 | 独立套一层大表单与重复页面标题 |

历史、导入导出、完整属性、版本比较仍可访问；“简洁”不通过删除必要功能实现。异常、冲突与保存失败必须有清晰入口。

## 统一的详情版式

规划节点、角色卡、世界设定共用 DetailShell。宽屏可在左侧保留轻量目录/画布；窄栏打开详情即进入专注页，隐藏原首页工具栏。

顺序固定：

1. 单行返回路径与右侧编辑/更多。
2. 一行类别、分组、状态。
3. 清楚的标题。
4. 摘要作为导语；无摘要时不占一个空框。
5. 全文自然排版。已有小标题、列表有对应样式；普通文本保留段落，不强制转换、改写或补造结构。
6. 内容之后显示前后情节或关联人物，默认简洁链接，不把关系工具放在正文前。
7. 更多属性默认折叠；删除在更多菜单末项。

阅读和编辑维持同一内容宽度与标题位置。切换只改变可编辑性和操作栏，避免全文突然跳入多层输入框。资料和规划现阶段仍有显式保存，因此正式改造不得假装它们已经自动保存；若后续统一自动保存，必须接入版本冲突和本地草稿机制。

## 微交互

| 行为 | 提案 |
| --- | --- |
| 按钮悬停 | 120ms 背景/颜色变化，无位移 |
| 按钮按下 | 80ms 轻微压低反馈，松开复原 |
| 打开详情 | 160ms 淡入与 4px 内移动，布局空间预先保留 |
| 折叠菜单 | 120ms 淡入，Escape 关闭，焦点回到触发按钮 |
| 阅读/编辑切换 | 原位切换，保留滚动位置 |
| 节点拖动/连线 | 跟随指针实时响应，不对拖动位置加缓动 |
| 保存 | 固定状态区“保存中/已保存/失败”，不弹成功通知，不重排页面 |
| 减少动态效果 | respects prefers-reduced-motion，取消非必要动画 |

悬停不是唯一发现方式。触摸和键盘必须能访问所有节点操作；图标按钮有名称与焦点样式。菜单包含真实按钮，不依赖小字提示来解释。

## 组件划分

- WorkbenchShell：作品选择与三项主导航。
- ModuleToolbar：一行主操作，搜索和更多菜单。
- DetailShell：返回路径、内容主体、主操作和折叠属性。
- DocumentContent：标题、导语、全文、行宽和滚动；阅读与编辑一致。
- ContextLinks：规划的前后节点、资料的关联条目；内容适配，版式统一。
- ActionMenu、IconButton、SaveStatus：统一控件和状态。
- MotionTokens：统一时长、缓动、减少动态效果支持。

与现有 Store、规划事务、Agent 工具、正文自动保存分离。前端重排不改小说数据结构，不自动改正文、设定或连线。

## 实施顺序

1. 本轮完成前三项清理，并制作原型供讨论。
2. 确认视觉方向后，先提取公共样式与 DetailShell，同时替换规划详情和资料详情。
3. 再压缩规划首页和资料列表；保留分组、导入、历史的可发现入口。
4. 最后接入微交互、主题适配、键盘导航和响应式细节。

## 验收标准

- 420×900 的规划首页，作品导航与工具区目标不超过 160px；不出现多排管理按钮。
- 420×900 的详情页，内容较短时第一段全文在约 320px 内出现；不保留首页搜索/新建工具栏。
- 正文、资料和规划详情均无嵌套正文滚动框。
- 360/420/900/1200px 下，无横向页面溢出；画布自身可以横向滚动。
- 字符很长、正文很长、没有摘要、没有关系、保存失败、真实冲突均有明确显示。
- 键盘可操作，焦点可见；减少动态效果生效。
- 自动保存、复制保格式、分组、图连线取消/删除、导入导出和版本恢复回归通过。
- 原型里的示例文本仅用于验证布局，不写入作者作品；原型中的编辑只作用于当前页面内存。

原型：同目录 prototype.html。运行 `node scripts/preview-design.mjs --serve` 可在浏览器查看；`node scripts/preview-design.mjs --check` 会截图并检查窄屏与详情交互。

## 2026-09-30：目录与新建流程补充

本次继续修改交互原型，正式插件仍为 0.2.7。示例目录和所有创建操作仅存在于当前预览内存，刷新会还原。

### 正文目录

- 将“新建目录”解释为新建分卷：每本作品只有一份章节目录，目录下按分卷组织章节，不增加另一套目录数据模型。
- 宽屏支持整体收起，正文扩展占用空间；工具栏保留“目录”入口。窄栏采用可关闭的侧边目录，选章后自动收起，Escape 关闭并回到触发按钮。
- 每个分卷可以单独折叠。目录支持搜索，当前章节高亮；长标题可以换行，右侧字数保持固定位置，不被挤掉。
- 每章显示实际字数，空章节显示 0 字。沿用现有统计口径：含标点、不计空白，按 Unicode 字符计数；目录底部显示章节数与总字数。
- 原型中的字数随当前正文输入同步变化。正式实现应区分已保存统计与本地草稿统计，当前章可用本地值，其他章节使用接口返回值，不为显示目录加载全部正文。
- 新建章节、分卷集中在目录标题旁的“＋”菜单，不为每一卷重复放一组按钮。

### 两类创建界面

| 创建对象 | 版式 | 必填与默认值 | 完成后的去向 |
| --- | --- | --- | --- |
| 分卷 | 居中的简短窗口：名称、取消、创建 | 只填名称；重复名称给出原位提示 | 回到目录；从章节创建页进入时自动选中新卷 |
| 规划/资料分组 | 与分卷相同的小窗口 | 只填名称；与所属模块隔离 | 回到原页面，保留已写内容并选中新分组 |
| 章节 | 完整内容页，沿用正文宽度 | 标题必填，正文可空；继承当前章节所在卷，可选未分卷 | 进入该章编辑，开始写正文 |
| 角色卡 / 世界书条目 | 统一新建内容页，顶部轻量类型切换 | 名称必填；摘要、全文可后补；不强制人设模板 | 进入统一阅读详情 |
| 规划节点 | 同一套内容页 | 标题必填；摘要、全文自由组织；继承当前分组 | 进入节点详情 |
| 接着推进 | 节点创建页上方显示来源情节 | 继承来源分组；不要求给连线填写属性 | 创建成功时一并产生节点与连线 |

### 布局与交互约束

- 页面顶部固定一行“取消 / 新建对象 / 创建”，不会因正文变长把提交入口推到页面底部。
- 内容顺序：归属分组或分卷、名称、摘要、全文。正文只保留标题与正文；资料支持角色卡/世界书切换。仅名称必填，不让用户先填完所有资料才能开始。
- 新建内容不套大弹窗，也不与底下的列表工具堆叠。容器名称这类短任务才用小窗口。
- 分组/分卷可在创建内容时就地新建，返回后保留标题、摘要与全文。
- 未填名称时，在名称旁提示并聚焦，不弹成功消息。取消内容创建不写入条目，不留下空节点或连线；已单独创建的分组/分卷保留。
- 切换资料类型保留已输入文字；未手动选择分组时匹配默认类别。明确选择的分组不擅自替换。
- 原型已演示临时离开创建页后再次新建同类型可恢复最近草稿。正式接入应使用按作品、类型和续接来源隔离的草稿存储，并保留异常/冲突状态；原型不宣称刷新可恢复草稿。
- 新建长内容只使用一个滚动区域；适配 360/420/1200px。宽屏收起目录保留正文阅读位置，窄栏抽屉用原生焦点约束。

实施时继续复用现有 chapter/volume/graph/planning 工具和事务，不把原型的内存操作复制为生产存储逻辑。规划续接仍使用原子的 `planning.continue`，资料分组沿用已有 groupId。

## 2026-09-30：资料关系图与随线信息

按作者最新意见，资料连线信息为可选内容，不要求每条关系填写名称，也不使用“未命名关系”“暂无说明”等占位文字。

- 资料保留默认列表，在同一行主工具区切换到关系图；点击卡片仍打开统一内容详情。
- 名称、说明均有内容时，在线旁按名称、说明两层显示；只有其中一项时，仅显示已有内容。两者都为空或只有空白时，只画连线与方向。
- 信息直接放在连线附近，以轻量文字和纸色底避开线条干扰，不增加独立边信息面板、底部关系表或详情页重复说明。
- 较长说明默认显示两行，点击后仍在原连线位置展开；展开区限制高度，避免覆盖节点。触摸和键盘均可操作，不只依赖悬停。
- 搜索时，隐藏节点的关联连线及其文字一并隐藏；不会在画布上留下没有来源的说明。
- 角色与世界书条目允许跨分组连接。原型使用独立的示例关系数据，包含有名称、有说明、只有说明、完全无说明四种情况；未接入正式作品。
- 本轮只验证关系图显示、节点导航、搜索和缩放。新增/修改/删除连线的完整交互在正式接入时复用现有能力，再沿连线提供情境操作，不默认展开边属性表单。

正式接入时，需要同步调整当前前端关系编辑器对名称非空的要求，并核对 Store、工具 schema 和 Agent 使用说明对空名称的支持。已有关系内容应完整保留，不因为画布收纳或省略显示而清除数据。

## 2026-09-30：设定命名与规划版面统一

- 原型中“资料”统一更名为“设定”，覆盖主导航、新建入口、返回入口、相关条目标题、画布说明及可访问名称。内部 memory 标识与正式插件数据结构不改动。
- 规划与设定共用同一个主工具栏：模块名、列表/图切换、搜索、新建、更多。规划称“流程图”，设定称“关系图”，不混淆两种连线的含义。
- 规划的列表切换从“更多”中移出，和设定使用相同的双选按钮；去掉重复菜单入口与画布常驻教学文字。
- 两种图共用卡片宽度、标题字号、辅助信息、边框与选中效果。规划显示“情节 + 状态”，设定显示“类别 + 分组”，内容语义保留。
- 规划的分组筛选放在画布左上角；列表模式放在列表上方同级筛选位置。切换视图保留分组和搜索条件；从详情返回时回到此前的列表或图。
- 左下角缩放工具、右侧详情与窄栏专注页沿用统一样式。本轮仅更新原型和设计文档，不部署正式界面。

### 常用分组操作的位置修正

按作者反馈，“＋ 新建分组”属于常用操作，直接放在分组/筛选区域，规划和设定的列表、图视图均可见，不放入省略号。新建内容页中的就地创建分组入口继续保留。此前关于将新建分组收进“更多”的安排以此修正为准；历史等低频操作仍留在“更多”。本轮移动入口，不代表设定分组筛选的后续设计已全部实现。

### 分组筛选已接入原型

- 设定列表与关系图共用一行“全部分组 / 全部类型 / ＋ 新建分组”。分组支持全部、未分组及用户创建的组；类型支持全部、角色卡、世界书。
- 分组、类型与标题/摘要搜索取交集。切换列表和关系图保留条件；匹配数量随搜索更新，窄栏隐藏数量以优先保留筛选和新建入口。
- 未命中节点及其相关连线、连线文字同时隐藏。过滤与缩窄窗口后，画布移动到匹配节点附近，避免命中结果全在屏幕外。
- 空结果显示“没有匹配的设定/情节”与“清除筛选”，不把筛选结果为空误报成数据丢失。
- 从常驻入口创建新分组后自动选中该组；新建角色/世界书条目继承当前分组，切换创建类型仍保留明确选定的归属。选择“未分组”创建时不默认塞进某个示例分组。
- 规划同时补齐未分组、空结果和搜索后的匹配数量。此节取代上一节关于筛选尚未接入的状态描述。
- 仍仅为内存原型，不修改正式小说数据；跨组关系按需展开、分组改名/删除/移动等完整管理交互不属于本次筛选接入。
