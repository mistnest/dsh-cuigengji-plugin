# 适配变更（未发布）

## 0.2.2 简化画布操作

- 前端连线统一显示普通箭头，隐藏关系类型选项与文字标签；旧数据仍兼容保留。
- 画布只常驻“连线”和“视图”，缩放、适应视图和整理布局收纳进视图菜单。
- 连线可通过按钮、再次点击起点或 Esc 取消，连接成功后自动退出。点击已有箭头可删除，修改记录支持撤销。

## 2026-09-29 正文排版与画布连线

- 移除正文中的“设为 Agent 当前参考章节”和重复的“查看 AI 参考”入口；全局项目接手信息仍可查看。
- 正文编辑支持自动排版与撤销：段首空两格、段间空一行，只改本地草稿，手动保存后写入版本记录。
- 规划画布增加“连线节点”：选择关系类型，依次点击起点与终点，即可保存连线；详情中的关系编辑仍可使用。

## 2026-09-28 项目接手与按需读取

- Agent 改为写作助手：每轮只接收有限的项目索引、当前任务和章节元数据，不自动注入正文、预设、规划或图谱内容。
- 新增纯数据的 `novel.handoff`，正文通过 `chapter.get` 分页读取，预设通过 `preset.read` 读取有效文本，规划和人物/世界资料按任务检索。
- 接手索引、文字渲染和 DSH 提示词适配解耦；AI 参考抽屉展示同一份接手说明，章节正文继续收在正文工作区。
- 删除旧的自动上下文拼装残留，重组 Skills 的项目接手指南，保留 CAS、版本历史和绑定隔离。
- 验证：50 项自动测试、构建、TypeScript 检查、diff 检查和桌面/窄屏浏览器烟测通过。
- 系统提示词改为稳定的静态写作助手前缀；项目接手索引不再每轮自动组装，Agent 需要时调用 `novel.handoff`，减少动态数据对模型前缀缓存的影响。

目标：DSH 0.1.7-rc.2 / Node 24 / Windows。

- 前端正式导出 `./client`，构建器使用包名注册模块。
- RPC 独立到 transport，改用 Connection 精确 Fetch route，与宿主 API Gateway 共存。
- 工具动作共用契约；修复 edge.get、Agent 入口未定义 readAction。
- 单独的会话策略与提示词模块，未绑定会话不注入小说 persona。
- Agent 正文写入取消规划批准门槛；保留绑定隔离、CAS 与正文历史。
- 修复 Windows 目录 fsync 兼容、MCP 重连时旧进程清理竞态。
- 旧项目 JSON 迁移预览、报告、确认导入和同 ID 冲突保护。
- 弹窗提取为独立原生 dialog 组件，支持焦点约束、Escape 和卸载时取消。
- 公共界面接入 DSH locale，继续使用宿主主题变量。
- 增加实际注册工具执行测试和完整 DSH RPC 流程脚本。

本轮备份升级 v2，兼容 v1 导入，首次读取旧规划先备份再迁移。没有发布 npm。

- 自动小说参考改为 Markdown 分节，按作者要求取消字符预算和截断；取消人物／世界设定自动注入，改为正文关键词检索及工具按需读取，更新写作查阅规则和资料页。

## 2026-09-27：协同规划与工作台

- 规划改为节点、层级、故事线和三种关系，提供 planning.list/search/get/history/changes/apply/revert；作者与 AI 共用，按工具调用读取。
- 事务原子性、CAS、重试去重、删除范围确认、撤销、来源引用和迁移备份。
- 前端分离画布与事务模型，提供流程图/列表、折叠目录、故事线筛选、阅读/编辑、变更比较与历史撤销。
- 导航为正文/设定/规划/预设，AI 参考独立返回入口；正文历史独立面板，设定列表/详情与局部关系图，预设单条编辑，备份分步导入。
- 关联正文可查看历史引用版本；跳转章节不改变 AI 参考绑定。
- 不自动加载规划或设定；保持全文自动参考且不添加字符预算。
- 验证：43 项自动测试、50 次真实 RPC；新版视觉验收待完成。
