# 更新记录

## 0.3.13 画布优先

- 规划与设定统一为一条轻工具栏、蓝白卡片和角落视图控制；新建分组直接可见，帮助与次级功能收纳。
- 用世界坐标与本机视口替代有限滚动区域，支持正负坐标、鼠标位置缩放和按页面保留视野；封住浏览器聚焦卡片时的隐式滚动。
- 单击选择、双击详情，空白框选与多卡移动；右键短按显示对象菜单，右键拖动平移。连线可断开，拖到空白可新建并连接。
- 讨论框可包围选择并带动内部卡片，支持只移动框、拖角调整尺寸和完整内容页；旧框保留原行为，删除框保留内容。
- 布局批量保存、版本冲突检查、相同请求重试和本次画布布局撤销/重做；设定新增原子移动、创建连线、复制、删除与断线工具。
- 更新规划与设定 Skill，保持正文与设定按需读取；新增隔离画布演示和失败/响应丢失复现场景。

## 0.3.12 公开源码与作品数据分离

- 将此前验证的正文、规划、设定、预设与桌面适配同步到公开源码仓库，不携带私人作品或其提交历史。
- README 改为面向作者的项目介绍；安装、数据管理和维护说明分别整理。
- 增加 MIT 源码许可证、项目链接和防误提交规则；去除依赖作者机器目录的安装默认值。

## 0.3.11 画布直接滚轮缩放

- 规划和设定画布直接使用滚轮放大/缩小，无需 Ctrl；保留拖动空白平移和视图菜单。
- 批注等可滚动文字区仍优先滚动内容，菜单与输入区域不被画布缩放拦截。
- 更新操作说明，并使用两类实际画布验证滚轮缩放及缩放后的拖拽、连线、布局保存。

## 0.3.10 预设内容优先导入

- 支持完整 Chat Completion、嵌套 PromptManager 与独立系统提示词 JSON，统一处理平铺/多方案排列。
- 忽略酒馆触发、插入位置和消息角色，保留提示词原文；含宏文本不再被自动停用。原始启停和排列保留，缺失内置槽位引用会报告。
- 显示有效条目与字符数、空内容提示和宏说明；旧版预设不自动改变启停状态。
- 官方默认预设前端实测由 0 变为 78 字符，新增 test:presets 覆盖三类上传、保存、恢复与原始文件下载。

## 0.3.9 目录关闭与宿主蓝色主题

- 目录抽屉关闭按钮使用独立顶部栏和 44×44 点击区域，长目录滚动不遮挡关闭入口。
- 界面强调色从绿色成功状态色改为继承 DSH 主题蓝色，统一按钮、筛选、选中与焦点样式；独立预览回退为蓝白配色。
- 新增 test:directory，验证关闭区域四角、中央、滚动、Esc、桌面收纳与深浅主题。

## 0.3.8 写作预设自动生效

- 提示词不含预设版本号、时间戳或原始导入文件；重复组装只保留一份，切换作品或停用时替换/移除。
- 同步预设界面、导入提示与 Agent 写作/修订指南。

## 0.3.7 统一正文与多页讨论画布

- 正文合并阅读和编辑模式，保留自动保存、排版、复制、历史与冲突处理；长正文保存及远端更新保持滚动位置。
- 规划新增独立页面、用途摘要和批量跨页移动；续接自动继承起点页面，禁止跨页连线。旧规划归入“主线规划”，读取旧备份不改写数据。

- 页面和批注接入版本检查、原子事务、撤销与工作数据导入导出；批注冲突保留草稿并支持人工合并。
- 更新 Agent 规划 Skill 与工具说明，新增通过实际工具验证的页面/批注示例，不增加动态上下文注入。

## 0.3.6 画布直接操作

- 规划与设定共用 TypeScript 画布交互：整卡/标题拖动，输入/输出圆点拖线，实时预览、有效落点高亮、点击或键盘连接；移除强制连线模式和设定连线时的必填表单。
- Esc、空白落点和指针取消均不提交；点击线后可删除，设定关系说明仍可在线上展示与展开。
- 空白处拖动平移、Ctrl + 滚轮缩放，拖线/拖卡到边缘自动平移；缩放与滚动后的坐标仍准确，拖动不会误开详情。
- 松手自动保存布局；保存后等待索引读回再接受下一次拖拽，防止旧版本连写。协作冲突保留本地位置供重试或还原，不覆盖 Agent 正文修改。
- 设定节点新增可选 position 坐标，支持严格校验、CAS、清除坐标和导入/导出；旧数据继续使用自动排布。
- 新增 test:graph，覆盖两类图的实际浏览器拖拽、连线、取消、键盘、平移缩放、重载、失败重试/还原和协作冲突。
