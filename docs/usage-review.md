# 使用审阅

本项目的交互以正文、规划与设定为主。查看当前使用方式，请从 [README](../README.md) 和[安装说明](getting-started.md)开始；旧版本的自动参考、规划批准门槛和分离阅读/编辑模式不再是当前行为。

需要重点检查的写作体验：

- 长正文编辑、自动保存、目录收纳、版本恢复和冲突时草稿保留。
- 规划与设定的分组搜索、详情返回位置、拖拽连线、取消和删除。
- 规划独立页面、批注与背景框是否有助于作者和 AI 讨论推进。
- 酒馆角色卡、世界书和预设的预览、取消、导入及有效内容核对。
- 宽窄面板、深浅主题、键盘、下拉菜单与入口可达性。

浏览器交互验证使用隔离临时作品；接口测试不替代页面和模型实际使用。模型能否理解作者意图，还需要用真实创作场景持续观察。最新检查记录见[验收说明](test-report.md)。
