# 规划与设定工作台

规划用来和 AI 讨论故事怎样发生；设定用来整理人物、地点、规则等可用资源。两个模块共用「内容目录 + 画布 + 详情」操作方式，内容按需读取，不因作者点开页面就自动加入 AI 上下文。

## 内容目录与画布

规划先选择一张画布，目录只显示这张画布里的内容。画布可以是全局走向，也可以是一次决战的局部推演；事件是冲突、选择、转折或阶段，不要求等于一个章节。阶段可以包含子事件，和文件夹一样展开、收纳。

设定直接以文件夹作为画布范围：打开「萧家」就看到该文件夹里的资源，不另维护一套画布列表。人物和世界设定可混排，类型通过图标和筛选区分。根目录可直接放条目，也可建立嵌套文件夹。

目录空白处右键新建内容或文件夹；文件夹菜单可新建子目录。拖动条目调整同级顺序、移入或移出文件夹，同级也可按 Alt+↑/↓。目录排序不改变卡片坐标、剧情因果或连线。搜索与多选时停用排序，避免看不全的目录产生误移动。

目录逐层展开文件夹和情节阶段，不会一次展开所有后代。搜索标题、摘要或故事线时，命中项保留完整的父级路径，只显示匹配内容及必要的上级；搜索期间可以手动折叠，清空搜索后恢复原来的展开状态。搜索只筛选目录，不改变画布上的卡片、坐标或连线。批注留在画布，不混入内容目录或目录搜索。

单击选择并定位卡片，双击或 Enter 在右侧打开详情。左侧目录和右侧详情均可拖宽，覆盖画布但不改变相机、卡片坐标或连线；两侧贴合后继续拖动，会联动调整另一侧。把目录向左拉、或把详情向右拉，就能重新露出画布。贴合处保留两条独立拖柄，也支持方向键微调。宽度与目录开关保存在此设备；窄面板打开详情时暂时隐藏目录，拉宽后恢复原偏好。

规划保留画布选择和页内目录；设定保留全书文件树，展开文件夹与进入对应画布是独立操作。返回后保留筛选、选择、草稿与画布视野。单选时不弹出额外操作条；右键菜单可整理、复制或删除条目。「多选」在顶部显示批量操作，可收纳为文件夹、阶段，或移动到已有文件夹、画布；筛选不会清除已选但暂时隐藏的条目。根目录直接放条目，不另外显示「未分组」。

## 直接操作

- 画布支持正负坐标；默认滚轮围绕鼠标缩放，捏合、Ctrl / Command 加滚动也可缩放。触摸板可在设置中选择双指滑动平移。右键、中键或空格加左键拖动也可平移，右下角「− / ＋」可直接缩放。
- 空白拖动框选，Shift 追加选择，多张卡片可一起移动；Esc 取消未完成操作。
- 右键空白在落点新建情节、设定、便签或讨论框，确认后保存，取消不留下空对象。
- 拖动连接点或依次点击可连线；规划拖到空白可新建并连接，右键连线可断开。
- 规划线有方向；设定按位置选端口。相关分支与汇聚使用共用连接点，悬停或选中可突出相关关系。
- 文件夹和阶段可折叠成一个整体，保留跨边界关系；讨论框可以转换成文件夹。
- 「自动排布」先预览，确认后保存；版本变化会要求重读。布局撤销/重做不覆盖后续内容修改。
- PNG / SVG 可导出全部内容、所选区域或当前视野；选择范围与折叠状态以导出预览为准。

「设置 → 编辑与外观 → 画布连线样式」可选「整理连线」或「经典曲线」。前者使用圆角避让和共用连接点，后者使用独立平滑曲线。规划与设定同时生效，图片导出沿用当前选择；切换只改变显示，不修改卡片位置、关系或目录顺序。偏好保存在此设备，默认使用整理连线。

「画布滚动操作」默认使用「缩放画布」，保留原有鼠标滚轮习惯。触摸板用户可选择「平移画布」，用双指滑动平移；选择会保存在此设备。两种模式都支持捏合与 Ctrl / Command 加滚动缩放，横向滚动可左右平移。可滚动便签和编辑框保留自己的滚动；画布移动不会修改卡片内容、坐标或版本。

卡片保持等比缩放，长标题省略、悬停可看全文。规划和设定详情里的「改动对比」统一查看历史版与当前内容的差异，包括标题、摘要、正文和变化的内容属性；可跳转上下处改动、切换并排与行内显示，窄面板自动行内显示。查看不会修改草稿。恢复时保留当前目录、画布位置与连线，只恢复这张卡片的内容，不撤销同批修改的其他卡片；未保存草稿会先确认保存。恢复形成新版本，替换前的内容和原历史仍可找回。升级前从未留档的历史无法补造。

对比页的「···」提供删除所选旧版本、按日期清理及保留最近若干版，预览范围后确认永久删除，不另存清理备份。当前版本保留，卡片当前内容、目录、位置和连线不变。规划清理会实际移除目标版本的全文快照；同批其他卡片的记录保留，但包含已清理快照的整批事务不能再整体撤销，可从其他卡片各自的改动对比恢复。详见[历史与回收站清理](workbench.md#清理历史与回收站)。

## 和 Agent 一起用

先找相关画布或资源文件夹，读标题摘要，再读有用条目的全文。复杂多方行动可按行布置，汇入共同结果；局部推演可另开画布。简单情节不强制画复杂网络，也不为图好看编造关系。便签适合未决问题、台词、伏笔，框适合讨论区域。

`written` 只表示情节已在保存的正文里实现，须引用有效正文版本；它不是每个节点必须达到的状态。一个章节可以落实多个事件，一个事件也可跨章。规划是意图，正文是事实，不能相互代替。

| 工具 | 用途 |
| --- | --- |
| `planning.pages` / `planning.page.*` | 读画布用途，创建与管理页面 |
| `planning.groups` / `planning.group.*` | 嵌套文件夹与归组 |
| `planning.list/search/get` | 先摘要索引，再相关事件全文与邻居 |
| `planning.decorations` | 按页读取便签和讨论框 |
| `planning.apply` / `planning.continue` | 原子更新多对象，或续接前后事件 |
| `planning.layout` | 按需自动安放、整理布局 |
| `planning.history/changes/revert` | 变更、增量和带版本保护的撤销 |
| `planning.node.history/restore` | 按需读取单卡版本与恢复内容，不撤销同批其他卡片 |
| `graph.list/get` | 先按名称或摘要筛选，再读取人物与世界资源全文 |
| `graph.update` | 修改原卡，支持局部替换 / 删段和完整重写；影响摘要时同时更新 |
| `graph.delete/remove` | 软删除整张或多张设定卡及相连关系，保留历史 |
| `graph.group.*` / `graph.arrange` | 整理资源目录与画布 |
| `graph.history` / `graph.restore` | 明确需要时读旧设定或恢复 |

写入前重读最新对象，携带版本号与 `requestId`。相同请求重试不重复创建；冲突后保留拟稿，重读并合并，不能仅抬高版本号重发旧全文。目录、阶段、资源引用和 JSON 事务例子见安装包的 `cuigengji-plan`、`cuigengji-memory` Skill 及其 `references/operations.md`。

让 AI 修订设定时，可以直接要求改某句话、删掉某项能力或重写资料。AI 在授权范围内可以删冗余、替换旧描述和重组段落；原卡 ID、未涉及的信息和引用继续使用，旧版本留在修改轨迹里。局部编辑用 `graph.update` 的 `patch:{oldText,newText}`，原文必须唯一匹配，`newText:""` 删除这段；整体重写用 `content`，两种方式二选一。设定摘要和相关关系按实际影响一起维护，不会由工具自动推断。

更新结果包含 `changed`、`changedFields`、`previousRevision` 与当前内容；未变化时不新增版本，参数有误或原文定位不准会明确报错。整卡删除用 `graph.delete`，返回 `deleted:true` 及 `deletedEdgeIds`；普通检索排除软删除项，原资料与历史保留用于恢复。`retired` 仍可被搜索，用于保留停用资料；它和删除是两种操作。
