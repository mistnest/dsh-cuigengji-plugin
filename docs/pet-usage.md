# 桌宠用量、费用与气泡

入口：**设置 → 桌宠与记录 → 用量、费用与气泡**。在原有大肥鱼 / 催更姬桌宠上显示数据，不需要再安装一个记账挂件。

点击桌宠打开紧凑速览，再点一次或按 Esc 收起。上方显示设备当日 Token、估算花费和账户余额，金额保留两位小数、不同币种分开列出；点开可看 Token 构成和余额来源。下方保留当前作品的正文净增与设定字数，展开「今日写作」查看规划修改和作者聊天字数。「查看记录」进入原有的写作记录页，查看日期统计、详细账单和模型定价。

点击整行可展开或收起明细，箭头同步转动。浮层打开后保持上边缘位置，靠近屏幕边缘时只滚动中间内容，关闭按钮与「查看记录」始终留在上下两端。账户来源占满整行，长作品名自动省略，长金额会缩小字号以保持完整显示；关闭动效后，展开和收起会立即完成。

多账户余额按原始精度汇总后显示，速览最多展开八个来源，完整账户列表在记录页。未连接余额显示「未连接」，未计价调用单独标明。自定义气泡内容保留在折叠区；开启轮换后，下次展开会切换内容。

## 记账口径

- Token 来自 DSH 报告的 usage。未缓存输入、缓存读取 / 写入、输出分别记账；推理量已经包含在输出里，不重复相加。
- 同一次尝试的流式与最终消息替换结算；模型重试分别统计。分支继承的历史前缀不重复记账，重启按游标回填。
- 每条明细保存调用时的价格、峰谷时段、原币金额与汇率。已计价明细保留原快照；补充单价后会补算此前未计价的请求。
- 宿主只报告部分 Token 时，按已报告的拆分估价并标明；未报告的用量不补造。未知模型、无有效用量或拆分矛盾的请求保留为未定价，不显示成免费。
- 模型估算与账号余额观测分开显示。余额下降可能含其他设备的支出；增加可能是充值或赠金。校正需要作者确认，不能将两类金额相加充当精确账单。
- 内置 DeepSeek 峰谷规则标注来源与覆盖年份，识别 DSH 的 `deepseek`、`deepseek-official`、`deepseek-account` 路由。额外 Search / Fetch 等接口费以厂商账单为准。

在 **写作记录 → Token、费用与余额** 中，选择今天、近 7 天、全部或自定义起止日期；按来源、模型进一步筛选。顶部显示费用、当前余额和 Token 构成，下方切换模型汇总、账户余额与调用明细。单日趋势按两小时分段，较长区间自动合并；费用趋势按币种分别查看。导出包含整个筛选区间的明细，保留原始精度。

## 模型价格

点击报表中的 **模型定价** 或模型名称，即可编辑对应价格；**设置 → 桌宠与记录 → 用量、费用与气泡 → 模型价格** 也使用同一个编辑器。DeepSeek 预填官方峰谷单价，默认按调用发生的北京时间选价：周一至周五 09:00—12:00、14:00—18:00 为峰价，中国法定节假日全天为谷价。已知 DeepSeek 模型经第三方网关调用时可使用官方参考价，实际折扣可用自定义价格覆盖。未识别的模型不会套用 DeepSeek 价格。

其他模型由用户配置单价：从已使用的模型中选择，也可手动添加。填写每百万 Token 的未缓存输入、输出、缓存读取单价；有缓存写入时再填写写入价。没有缓存的模型可填 0。支持人民币、美元、欧元、日元、英镑；外币可填写人民币汇率。若厂商分峰谷价，可分别填写两组单价，并修改适用星期、计价时区、节假日规则和多个时间段。时段包含开始时间、不包含结束时间，支持跨午夜，重叠时段不能保存。旧版未设置时间段的价格继续采用默认 DeepSeek 时段。

模型名和厂商标识精确匹配（忽略大小写与首尾空白）。厂商标识填 `*` 时同模型适用于所有厂商，具体厂商的自定义价优先，之后匹配官方路由别名、通配规则、内置参考价。自定义价优先于内置价；第三方网关可填写其实际单价。

保存后自动补算此前缺单价的本地请求；更新本功能时也会补算旧版漏计的官方路由。补算只补缺失费用，保持已计价明细、导入的小鲸鱼费用、Token、余额历史及回填游标。逐次明细显示使用的峰价、谷价或固定单价。

## 数据来源

34 个厂商模板提供接口默认值；也可以自行填写 HTTP 地址、认证模板和 JSON 字段路径。密钥只引用 DSH 凭据名，不保存在记账配置或导出包中。默认 DeepSeek 优先使用 API key，没有 key 时尝试 DSH 已登录账号。

有些厂商没有余额查询接口，模板仅提供连通性测试，此时依靠本地 Token 估算。模板存在不代表所有厂商已用真实付费账户验收；接口和套餐权限也可能变化。

资源包可填写总量与当前已用量，选择手动或从之后的新 Token 继续累计，以及每日 / 每月 / 不重置。来源可单独设置预算和低余额线。订阅额度直接显示接口返回的窗口与重置时间。

Codex 来源默认只读 `$CODEX_HOME/sessions` 和 `archived_sessions`，未配置环境变量时使用用户目录 `.codex`。也可指定日志目录。只保存计数、模型、偏移和窗口，不复制聊天正文，不改动 Codex 日志。

## 气泡与素材

气泡支持顺序轮换、加权随机。同一步并列组可在一个步骤中随机选择不同内容。每个气泡最多六行，每行最多六个模块；拖动模块可合并或拆行，图片独占一行。也提供按钮排序和常用模块库。

模块包括文字、统计、链接、随机文字、图片 / GIF、随机图片。可配置字体、字号、颜色、背景、渐变和字形。自定义文字支持 `{{tokens}}`、`{{cost}}`、`{{session}}` 等指标。

点击桌宠打开速览。完成、提问、授权、预算、余额、按下 / 松开仍可配置各自的声音和速览内容。打开速览后，可以从等待中的事项跳回来源对话。同一条提醒的音效只播放一次。

素材库支持透明 PNG / GIF 角色、气泡图、音频裁剪与音效组。Windows 使用系统透明窗口与 GIF 合成；网页受浏览器音频自动播放规则限制。内置轻提示音由项目合成，没有捆绑第三方游戏音频。

## 数据与备份

账本独立于小说库，默认位于 `$DSH_HOME/cuigengji/usage`，可由插件 `usageRoot` 或 `CUIGENGJI_USAGE_ROOT` 配置。它按 DSH 数据目录共享，不按小说或 profile 分开。关闭或隐藏桌宠仍可继续统计；关闭用量记录后不再补录该关闭区间。

明细按日期分文件，长期保留。完整备份含用量、气泡、来源引用、价格和素材；不含凭据或聊天正文。导入先预览、按请求 ID 去重。可选择恢复配置；同来源已有余额历史保留，缺少的来源与历史账户复制导入。恢复配置可能重新启用数据源，请先核对凭据引用。

支持复制导入小鲸鱼 `.dshw-usage.json` 的明细与余额历史。它只有总 Token 时不伪造拆分，也不重算原费用；该旧来源与 DSH 自动回填分别保留，查看时按来源筛选。其他小鲸鱼配置文件和外部状态脚本不是完整兼容导入格式。
