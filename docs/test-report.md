- 实际宿主前端验收侧栏入口、首次建书、正文读取/编辑/自动保存、规划、设定、写作预设与导入导出；同时验证五个工具和六个 Skill 注册、接手索引、MCP 与工作库完整性。页面和插件请求不得有异常。

- 验收使用合成数据，不操作作者正式 DSH/profile 或私人小说，不调用模型。各项结果、桌面版本、截图和最终归档哈希保存在发布工作目录 `releases/v0.4.5/`；任一必需检查失败都不分发。
