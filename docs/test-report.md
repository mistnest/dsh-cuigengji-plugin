# 公开版验收说明

日期：2026-10-03。源码版本 0.3.13，宿主基线 DSH 0.2.0-rc.2 / Node 24 / Windows。

## 0.3.13 画布专项验收

- `npm test`：93/93，通过坐标换算、鼠标锚点、负坐标往返、批量 CAS 回滚、重试去重、创建并连接及旧讨论框字段兼容。
- 注册宿主工具经真实 stdio MCP 验证五个新增设定动作：graph.layout、graph.continue、graph.duplicate、graph.remove、edge.disconnect。
- 通过 Codex 浏览器操作真实 Workbench 和临时 Store，使用原创《雨城来信》：卡片拖动、交错移动后的三步撤销/重做、框选、C 创建讨论框、整体移动/只移动框、调整尺寸、删框保留节点、端口拖线和断线、创建并连接及取消、分组筛选、独立页面、详情返回均实际检查。
- 直接滚轮缩放时，被指向端口的屏幕位置变化小于 1 px；打开批注再返回后 scrollTop 保持 0。负坐标保存并重载后保持位置和视野。
- 在隔离预览中模拟“布局已提交但响应丢失”，界面保留本地位置；点击重试后使用相同请求，仅保留一次布局事务和一次版本增加。
- 320、1024 px 窗口与默认桌面宽度检查，应用外壳无横向溢出；测试后清除临时窗口尺寸。

右键短按菜单已实际检查；右键/中键连续拖动与按住空格拖动的规则经代码审阅，本次浏览器工具未提供对应的持续按键手势，因此未声称这些手势已自动实测。没有运行 Unreal Engine 本体，也没有调用模型验证写作质量。失败布局暂存在当前画布实例，切换页或刷新之前应重试或还原；本次布局撤销栈不跨页面重载。

隔离试用：`npm run preview:workbench -- --canvas-demo`。可追加 `--fail-layout-once` 或 `--lose-layout-response-once` 复现一次保存失败；不会打开日常小说数据目录。

## 既有验证范围

此前迭代还分别检查过多页规划与批注、拖拽与连线、目录关闭区域、蓝色主题、下拉与常驻入口、酒馆资料和预设导入。复现脚本位于 `tests/ui-*.mjs`，本次没有重复运行全部专项界面脚本。

## 复现

```powershell
npm ci
npm test
npm run typecheck
npm run build
npm run test:ui
npm pack
```

专项交互对应 `test:graph`、`test:pages`、`test:directory` 和 `test:presets`。真实 RPC 回归请用独立 DSH 实例及小说数据目录运行 `test:rpc-flow`，该脚本会创建测试作品。
