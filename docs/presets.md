# 写作预设：当前支持范围

入口：作品名称旁「···」→「写作预设」。当前每部作品保存一份预设；这部作品的所有绑定会话使用它。

可直接新增提示词，也可导入含 `prompts` / `prompt_order` 的酒馆 Chat Completion JSON。存在多个排列时可选择；默认优先酒馆通用排列 100001。导入生成草稿，默认停用，核对后开启并保存。界面支持条目编辑、启停、上下排序、实际注入文本预览和下载原始酒馆 JSON。修改后的 DSH 配置随作品完整备份保存。

保存后下次 Agent 组装提示词时生效，不修改正在运行的请求。普通 system 文本按列表顺序注入插件写作说明之后；DSH 本身的工具、规划审批和会话边界继续生效。

## 兼容限制

- 暂不执行宏，包括 `{{char}}`、`{{user}}` 和变量宏。含宏的条目默认停用；可手工改为明确文本再启用。
- 暂不复现聊天历史深度、user / assistant 消息、动态 marker 或按生成事件触发。这些条目保留但停用并显示原因。
- 温度、top_p、模型、token 上限等参数仅归档，未设置 DSH 模型参数。
- 不支持纯采样预设、Instruct 和 Context 模板导入，不支持多预设库一键切换。
- 原始字段随备份保留，不代表相应行为已经兼容。实际生效文本在页面内可检查。

## 验证

自动测试验证了排列顺序、不支持条目的停用、作者权限、版本冲突、存储与完整备份恢复、停用后撤销注入、绑定会话实际组装文本及未绑定会话隔离。尚未用用户实际预设验收，也未完成浏览器交互测试。
