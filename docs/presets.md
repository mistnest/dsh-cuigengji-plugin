# 写作预设与会话指引

入口：「设置 → AI与写作 → 写作预设」。每部作品有独立的预设空间，浏览别的作品不会替 AI 切换当前工作目标。先告诉 AI 使用哪部作品，或让它用 `novel.list` / `novel.focus` 选择。

预设可以直接新增，也可导入 TXT、Markdown、完整 Chat Completion JSON（顶层 prompts）、PromptManager（data.prompts）或独立系统提示词。导入先预览、选择追加或替换，再写入当前作品的预设空间；「导入预设」不会把文本拆成正文章节。可从作品或工作库备份里只提取预设。导入后默认整体停用，核对内容再开启。

条目可编辑、启停、排序，支持多个排列方案，有效文本与原始 JSON 可查看或导出。编辑后的配置随作品备份保留；历史上误导入的章节不会自动删除。

## 当前会话写作指引

「设置 → AI与写作」提供当前会话开关，默认开启。已有会话主动关闭的选择会保留：

- 开启：核心写作规则和当前作品已启用的预设自动加入提示词，适合持续写作和讨论情节。
- 关闭：停止常驻注入，完整指引通过 `cuigengji_guidance` MCP 按需读取，适合写代码和其他任务。

关闭后 AI 可能不会主动使用催更姬，可明确告诉它「使用催更姬」。工具和 Skill 继续可用，已有聊天不删除。`cuigengji_guidance` 支持 core/project/write/plan/memory/revise/preset/all；未选作品时可读通用规则，预设返回未选择提示，不猜目标书。

预设启停和作品焦点在下一次提示词组装时生效。只提供有效文本，不注入时间戳、版本号、导入原文件或整本小说；正文、规划、人物与世界仍由 AI 按需查阅。

## 酒馆格式的边界

- 保留提示词正文、原启停与排列；不执行插入深度、触发条件、消息角色或酒馆装填规则。
- `{{char}}`、`{{user}}` 和脚本宏保留原文，不代填、不执行。复杂变量及 MVU 不在当前支持范围。
- PromptManager 缺失的内置槽位文本跳过并报告，不补造；空 marker 不产生文本，非空 marker 可使用正文。
- 温度、top_p、模型等参数只归档，不修改 DSH 的模型设置。只有采样参数或装填表达式的文件会提示缺少可用正文。
- 导入保留原字段不代表兼容其行为；实际使用哪些文字，以有效文本预览为准。

格式说明参考 [SillyTavern Prompt Manager](https://docs.sillytavern.app/usage/prompts/prompt-manager/)。
