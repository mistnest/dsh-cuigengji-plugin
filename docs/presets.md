# 写作预设：当前支持范围

入口：作品名称旁「···」→「写作预设」。当前每部作品保存一份预设；这部作品的所有绑定会话使用它。

可直接新增提示词，也可导入完整 Chat Completion JSON（顶层 prompts）、PromptManager 导出（data.prompts）或独立系统提示词（content/system_prompt，含 post_history/post_history_instructions）。支持平铺顺序及多个排列方案，默认优先通用排列 100001。导入生成草稿，整体默认停用，核对后开启并保存。界面支持条目编辑、启停、上下排序、有效文本预览和下载原始 JSON。修改后的配置随作品完整备份保存。

启用后，当前作品绑定会话在组装系统提示词时，将兼容条目的有效文本按顺序放在催更姬开场提示词后，作为作者写作要求，无需 Agent 主动读取。停用或切换作品在下次组装时生效；未绑定作品时不注入预设。仅注入有效文本，不加入时间戳、版本号、原始 JSON 或小说内容。预设不变时该部分提示词保持稳定，但实际缓存命中仍由宿主和模型服务决定。`preset.read` 保留用于查看配置和排查问题。

## 兼容限制

- 以提示词内容为主，不执行酒馆的插入深度、触发条件、消息角色或装填规则。任何角色的启用文本都按列表顺序拼接为作者写作要求，不模拟聊天消息。
- 宏（包括 `{{char}}`、`{{user}}`）保持原文，不执行、不猜测称谓，也不因含宏而停用整条。界面提示含占位符，可直接改写。复杂变量或脚本宏不会产生酒馆中的效果。
- 保留原文件选定方案的启停状态；没有排列时有正文的条目默认可用，显式 enabled:false 保持停用。空 marker 不产生文本，非空 marker 的正文可以使用。整体启用且无有效文本时会提示。
- PromptManager 导出可能没有包含内置槽位对应文本；跳过缺失引用并报告，不编造内容。完整预设的未知引用仍报错，避免无声丢失。
- 温度、top_p、模型、token 上限等参数仅归档，未设置 DSH 模型参数。
- 纯采样参数、只有分隔符的 Instruct、只有装填表达式的 Context 文件不包含独立提示词正文，会明确提示。包含 content/system_prompt 的文件可提取文本，但不执行其装填字段。不支持多预设库一键切换。
- 原始字段随备份保留，不代表相应行为已经兼容。实际生效文本在页面内可检查。
- 旧版已保存预设不自动启用此前被停用的条目；可手动启用，或下载原始文件后重新导入，使用新的内容优先规则。

## 验证

自动测试覆盖三种格式、排序与启停、原文宏、忽略触发/深度/角色、作者权限、版本冲突、备份恢复、提示词注入及跨作品隔离。test:presets 在正式前端的临时副本中实际上传、保存、刷新和下载，验证空文本提示；额外使用审查中固定的官方默认预设实测得到 78 字符有效文本。不调用模型，不修改正式作品。用户自己的预设仍需在导入后检查其具体内容。
