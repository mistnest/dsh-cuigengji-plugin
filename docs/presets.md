# 写作预设与会话指引

入口：「设置 → AI与写作 → 写作预设」。每部作品有独立的预设空间，浏览别的作品不会替 AI 切换当前工作目标。先告诉 AI 使用哪部作品，或让它用 `novel.list` / `novel.focus` 选择。

预设可以直接新增，也可导入 TXT、Markdown、完整 Chat Completion JSON（顶层 prompts）、PromptManager（data.prompts）或独立系统提示词。导入先预览、选择追加或替换，再写入当前作品的预设空间；「导入预设」不会把文本拆成正文章节。可从作品或工作库备份里只提取预设。追加保留现有预设的总开关和条目状态。首次导入或替换默认停用，核对后可开启。

条目可编辑、启停、排序，支持多个排列方案，有效文本与原始 JSON 可查看或导出。编辑后的配置随作品备份保留；历史上误导入的章节不会自动删除。

## 让 AI 导入与修改

可以直接告诉 AI「把这份文件追加到这本书的预设」「修改文风那条要求」或「停用这个条目」。AI 通过 `cuigengji_context` 的 `preset.get/preview/import/update` 读取最新保存的配置、预览导入及保存修改；MCP 也提供相同维护动作。明确要求导入后启用或停用时可以一并完成。

读取结构只服务于维护或明确查阅。正常写作直接使用自动注入的有效预设，无需每轮重新查询；「这一段换种写法」只调整本次正文，明确要求更新预设时才保存长期配置。修改前检查整套版本，保留未涉及条目、排列与导入原文；人机同时修改发生冲突时重新核对差异。

维护结果会显示在同一预设页面。工具写入独立作品的 `preset.json`，`preset.set` 供作者页面整套保存，AI 使用预设维护动作。

## 当前会话写作指引

「设置 → AI与写作」提供当前会话开关，默认开启。已有会话主动关闭的选择会保留：

- 开启：核心写作规则和当前作品已启用的预设自动加入提示词，适合持续写作和讨论情节。
- 关闭：停止常驻注入，完整指引通过 `cuigengji_guidance` MCP 按需读取，适合写代码和其他任务。

关闭后 AI 可能不会主动使用催更姬，可明确告诉它「使用催更姬」。工具和 Skill 继续可用，已有聊天不删除。`cuigengji_guidance` 支持 core/project/write/plan/memory/revise/preset/all；未选作品时可读通用规则，预设返回未选择提示，不猜目标书。

会话首次读取某本书的预设时，会记录当时的启停状态和有效文本。自动注入和 MCP 按需读取共用这份预设，续聊、重启或切回该书时都沿用。要采用刚保存的版本，请在新会话接手作品。写作指引开关独立生效，剧情变量仍按当前状态取值。

## 酒馆格式的边界

- 保留提示词正文、原启停与排列；不执行插入深度、触发条件、消息角色或酒馆装填规则。
- 宏在编辑和导入原文中保留。作品启用[剧情变量](variables.md)后可渲染支持的取值宏；任意 JS/EJS、写入宏和扩展脚本不在读取时执行，不代表兼容所有酒馆行为。
- PromptManager 缺失的内置槽位文本跳过并报告，不补造；空 marker 不产生文本，非空 marker 可使用正文。
- 温度、top_p、模型等参数只归档，不修改 DSH 的模型设置。只有采样参数或装填表达式的文件会提示缺少可用正文。
- 导入保留原字段不代表兼容其行为；实际使用哪些文字，以有效文本预览为准。

格式说明参考 [SillyTavern Prompt Manager](https://docs.sillytavern.app/usage/prompts/prompt-manager/)。
