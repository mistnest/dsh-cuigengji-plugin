# 写作预设：当前支持范围

入口：作品名称旁「···」→「写作预设」。当前每部作品保存一份预设；这部作品的所有绑定会话使用它。

可直接新增提示词，也可导入含 `prompts` / `prompt_order` 的酒馆 Chat Completion JSON。存在多个排列时可选择；默认优先酒馆通用排列 100001。导入生成草稿，默认停用，核对后开启并保存。界面支持条目编辑、启停、上下排序、有效文本预览和下载原始酒馆 JSON。修改后的配置随作品完整备份保存。

启用后，Agent 在当前任务需要遵循作品风格时通过 `cuigengji_context` 的 `preset.read` 获取有效文本。预设正文不会自动注入每轮提示词；读取接口只返回启用状态、版本和兼容的有效文本，不会把导入的原始 JSON交给 Agent。

## 兼容限制

- 暂不执行宏，包括 `{{char}}`、`{{user}}` 和变量宏。含宏的条目默认停用；可手工改为明确文本再启用。
- 暂不复现聊天历史深度、user / assistant 消息、动态 marker 或按生成事件触发。这些条目保留但停用并显示原因。
- 温度、top_p、模型、token 上限等参数仅归档，未设置 DSH 模型参数。
- 不支持纯采样预设、Instruct 和 Context 模板导入，不支持多预设库一键切换。
- 原始字段随备份保留，不代表相应行为已经兼容。实际生效文本在页面内可检查。

## 验证

自动测试验证了排列顺序、不支持条目的停用、作者权限、版本冲突、存储与完整备份恢复，以及 Agent 提示词不包含预设全文、按需读取只返回有效文本。尚未用用户实际预设验收，也未完成浏览器交互测试。
