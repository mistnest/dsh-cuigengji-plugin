# 工作台常用功能

## 正文编辑、行号与改稿对比

从目录单击章节即可打开正文，每次编辑一章。切换章节时，原章节的自动保存继续处理，保存失败的草稿保留在本地，重新打开即可处理。目录拖拽用于调整章节顺序。

正文目录默认倒序，后面的卷与章节显示在前；点击目录标题旁的「倒序 / 正序」可直接切换并记住选择。显示排序不改变章节编号、正文顺序或导出顺序；拖拽仍按屏幕上的落点调整实际章节顺序。窄面板的目录在插件区域内展开，不遮挡 DSH 聊天。

正文工具栏「行号」可开关显示，偏好保存在此设备，也能在「设置 → 编辑与外观」调整。行号按实际换行计算，自动折行不增加编号。点击底部「第 X 行」或在正文按 Ctrl+G，输入行号即可定位。

拖宽或收窄插件面板时，正文随可用宽度重新排版，行号同步对齐；不会改变正文内容和逻辑行数。

正文标题右侧「··· → 改动对比」统一查看旧稿与当前正文的增删差异，可选择对照版本、切换并排或行内显示，并跳到上下处改动。窄面板自动使用行内对比，大段未改内容可按需展开。查看不会修改正文；期间有新修改时可重新比较。需要恢复旧稿时，选择对应版本，点击「恢复此版」并确认。当前稿和更早的版本继续保留；正文有未保存修改或冲突时，先处理后再恢复。人机冲突仍通过明确的手动合并处理。

## 清理历史与回收站

正文和卡片的「改动对比 → ···」可删除所选旧版本，也可按日期清理，或保留最近若干版。当前版本与仍被设定、人物关系、规划或剧情变量引用的正文版本会保留，清理清单可展开查看引用。版本号不重新编号；清理规划卡片只移除该卡片的旧快照，同批其他卡片的历史仍可比较和恢复。

正文目录的回收站支持单项、多选永久删除及清空当前作品的章节回收站。首页「作品回收站」支持单项、多选及清空回收作品。永久删除先核对范围，确认后直接删除，不另存清理备份；如果内容或引用在确认期间变化，需要重新核对。

清理使用可恢复事务提交，中断后会完成同一笔删除，不会留下清理副本。确认窗口显示「删除后无法恢复」。需要备份时，请在「数据与备份」主动导出。删除不会清理此前导出的文件、其他备份或已冻结的写作记录。永久清理由作者界面操作，AI 的常规删除仍保留软删除和版本记录。

## 规划与设定

规划与设定也支持卡片「改动对比」，复用正文的逐行和字词差异显示；目录与详情面板可独立拖宽、贴合后联动调整，详见[规划与设定工作台](planning-board.md)。

## 正文查找与替换

正文工具栏点击「查找与替换」，也可用 Ctrl+F 查找、Ctrl+H 替换。浮窗可以在整个 DSH 窗口内拖动，底下的聊天与正文仍可操作；Escape 关闭，切换会话或收起插件会隐藏浮窗。

支持当前章与整本作品、区分大小写、上下处跳转和结果分页；点击片段定位并选中原文。替换当前匹配，或先预览再全部替换。当前章沿用自动保存和原生撤销/重做；全书替换一次核对所有章节版本并原子提交，保留每章旧稿。预览后章节被新增、删除或改动，会停止替换并要求重新预览。

整书查找会先保存本会话的正文草稿；未解决冲突不会被强行覆盖。回收站、历史稿和其他作品不参与搜索替换，替换文字按普通文本处理。

## 桌宠与写作记录

「设置 → 桌宠与记录」开启陪伴、切换大肥鱼或催更姬、重置位置、查看状态或重试。Windows 桌面版使用独立透明窗口，可以拖动、点击回应、右键操作；最小化 DSH 后仍可陪伴。网页、非 Windows 或原生窗口失败时回落为窗口内陪伴。当前未提供自定义桌宠包导入。

点击桌宠或设置中的「查看写作记录」打开独立统计弹窗。支持今天、近30天、本月和自选日期，按作品或全库查看正文净增、设定新增、规划推进与作者聊天字数；趋势图和每日明细可回看，作者与 AI 贡献可展开。「现稿」显示当前已保存、仍采用的正文总字数，不受日期筛选影响。

正文按操作当天的净增量记录：新增加字数，删减、章节或作品进入回收站减字数，恢复则加回。修改前几天的正文也只影响今天，跨天后原记录不再回算。比如昨天写 3000 字，今天删 500 字、又写 800 字，昨天仍是 3000，今天净增 300；如果今天只删 500 字，就显示 −500。按实际操作人计入作者 / AI 的净增贡献，含标点、不计空白，等长改写和纯排版净增为 0。

「现稿」始终按当前有效正文计算，回收站和历史版本不计入。每日统计与正文保存一并落盘，无需在午夜保持 DSH 开启；旧版已有日期记录原样保留。导入作品和完整库恢复不算新写作，不重复增加每日字数。

设定新增、规划推进与聊天仍记录已发生的活动。移动卡片和纯排版不算写作；聊天只保存字数，不保存聊天正文，没有作品目标的聊天不猜测归属。活动记录按年保存，不设180天滚动清理；关闭桌宠仍会记录，完整工作库备份包含统计及正文版本。

## 设置与作品库目录

设置按「编辑与外观」「AI与写作」「桌宠与记录」「数据与备份」分类，可跨分类搜索、恢复单项或分类默认值。设置说明标明影响当前会话、当前作品或此设备。

作品库位置在「数据与备份」里查看、选择和切换。可打开已有作品库、新建空库、将当前库迁移到空目录，也可从最近目录打开。迁移先备份并校验，成功后才切换；原目录不删除。请先保存编辑、等待写作结束，再切库。详细升级与恢复规则见[迁移说明](upgrade.md)。

## 导入和带走作品

首页作品卡片可直接导出整本作品；首页「导入作品」、作品管理及正文/规划/设定/预设的快捷入口，会预选对应范围。选择文件后先看目标与预览，再确认，详见[导入与导出](import-export.md)。
