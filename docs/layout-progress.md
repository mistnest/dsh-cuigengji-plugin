# 工作台排版改造进度

更新：2026-09-27。状态：实现已构建，视觉验收待完成。

## 已实现

- 顶部作品选择与正文、设定、规划、资料四个入口；备份归入作品操作。
- 正文目录按卷分组，可搜索；窄面板切换目录与正文，宽面板并排显示。
- 阅读、编辑分离，字号可选，保存栏固定在编辑区底部。
- 浏览章节和设置 Agent 参考章节分开操作。
- 规划、正文、人物与关系编辑使用按会话和实体隔离的草稿缓存。
- 草稿保留原始版本基准；比较远端后由作者明确更新保存基准。
- 来源选择使用章节名和版本；人物知情范围使用人物名称。
- 加载、空状态、失败重试分别呈现；章节读取失败可以返回目录。
- 空章节标题和空规划提示原因并禁用保存；保存中禁用章节属性编辑。
- 前端按正文、规划、设定、参考资料、管理和共享状态拆分模块。
