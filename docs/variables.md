# 可选剧情变量

入口：进入作品后，**设置 → AI与写作 → 剧情变量**。默认关闭，各作品独立。不用变量时，原有设定、规划与正文照常使用。

## 变量记录什么

人物等级、背包、关系值、任务标志等会随情节变化的数据。人物性格、世界背景和导演式规划仍用现有文字与画布表达，不强制将创作拆成数值表。

- **作品剧情**：作品共同的正式状态。
- **当前会话草稿**：该会话的推演，不会改其他会话的草稿或正式状态。
- **剧情位置**：初始状态或某章某版本的章首 / 章末。写前文时不会读到后文才出现的数值。

状态表可查看嵌套字段。路径用 JSON Pointer，例如 `/人物/主角/等级`；值填写 JSON，文本要加双引号。设置、增减、删除均先预览，确认后保存成新快照。变量说明、类型约束与关联角色 / 世界卡片均为可选项。

## 变化轨迹

每次正式提交保留来源、章节版本、原因、父快照与修改路径。浏览历史不写数据，也不自动送入 AI 会话。恢复历史值仍需选择目标剧情位置、预览和确认，会生成新快照，旧轨迹保留。

正文版本或早期状态改变后，受影响的后续状态显示“待核对”。核对后在当前正文版本提交修正；不删除旧状态，不因此阻止整本书写作。目录序号不作为快照的唯一定位。

工具提交使用 `baseRevision`、`requestId` 与明确的 `anchor`。原样重试复用 requestId，避免一次“加一”变成两次；不同字段可合并，同字段、父子路径和数组结构冲突需重读后决定。

## 酒馆 / MVU 的兼容边界

导入页读取 JSON 中常见的 `[InitVar]` JSON / YAML 初始化、字面量 setvar，保留原始来源。全局变量需作者确认转换为这本作品的状态，避免改变其他作品。

支持常见只读取值宏 `{{var::path}}`、`{{getvar::x}}`、`{{getglobalvar::x}}`，以及 user / char。MVU `stat_data` 映射到作品剧情；普通 getvar 是会话值；原全局值映射到本作品 `tavernGlobal`。

常见 JSON Patch 和 `_.set/add/remove/insert` 字面量可解析成补丁，再预览和提交。任意 JS、EJS、表达式和扩展状态栏脚本不会执行。不能把这个范围说成兼容所有酒馆卡或所有 MVU 扩展。

作品启用变量后，预设在读取时替换支持的宏，原文保留。AI 读取角色 / 设定可获得 `renderedContent` 与状态版本；编辑仍以原始 `content` 为基础，不能把某一章的临时值反写成整本设定。关闭写作指引时仍可通过 MCP 按需读取，不会绕过开关自动注入全部变量。

## 保存与迁移

每本书的 `variables.json` 保留配置、初始值、会话默认值与完整快照。完整作品 / 工作库备份保留轨迹；复用为新作品时重映射章节、设定与父快照 ID，默认停用，核对后再开启。

局部章节、设定、规划或预设数据包不附带整本书的变量，防止带走未选择的剧情和会话草稿；含宏的原文仍保留，可在目标作品初始化变量。
