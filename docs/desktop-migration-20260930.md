# 桌面版迁移说明

插件使用 DSH 官方 Windows 桌面应用；当前已验证的宿主版本为 0.2.0-rc.2。实际版本请以应用和依赖清单为准，不根据安装包文件名判断。

## 把小说从旧环境带过来

1. 在旧插件里保存正文和草稿，从“工作数据 · 导入/导出”导出小说数据。
2. 保留这份备份，再安装新 DSH 和插件；步骤见[安装说明](getting-started.md)。
3. 在新工作台查看实际数据目录，导入备份并核对作品、正文、历史、规划和设定。
4. 进入新会话时重新选择作品；跨环境的会话绑定依赖 DSH 会话 ID，不能仅凭小说文件推断聊天已迁移。

DSH 的聊天记录、附件、模型配置、凭据与界面偏好不属于催更姬小说备份。需要迁移它们时，使用 DSH 自身的数据迁移方式并核对原会话能否打开。不要把个人 DSH Home、小说导出或截图提交到公开源码仓库。

## 已有原始小说目录

在应用停止写入后保留整个旧目录副本。配置新插件的 `dataRoot` 或使用导出/导入；确认工作数据页显示预期目录和作品清单后再继续创作。不要让两套 DSH 同时写同一小说目录。

## 桌面运行时

Electron 的 `process.execPath` 指向桌面程序。插件启动 MCP 子进程时使用 Node 模式，避免误开第二个桌面窗口；普通 Node 与桌面内置 Node 都需要覆盖这条链路。

升级插件后需要完全退出并重启 DSH。安装脚本检查构建文件，不能替代重启后真实工作台的操作检查。

## 回退

回退之前先备份新环境里产生的作品和聊天。保留旧版本与升级前数据副本，但不要直接用旧备份覆盖升级后新增的正文。小说数据独立于插件源码，恢复作品不需要回退 Git 分支。
